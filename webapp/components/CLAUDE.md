# webapp/components — CLAUDE.md

## Component conventions

- **Three tiers, decided top-down:** a **primitive** (`ui/`), **chrome** (`shell/`: what `AppShell` mounts around every view, and what only it mounts), or **one surface** (a folder each; inside it, folders are domain regions, never widget kinds). A domain widget several surfaces host is a surface of its own (`candidates/`, `measurements/`), never chrome. A host hands a reading **IDENTITY props, never SOURCE props** ([`../lib/CLAUDE.md`](../lib/CLAUDE.md) § Display-data sources); shared state is a context in `lib/`.
- **No second modal, popover, dropdown, toggle-chip, segmented control, toolbar, clipboard copy, commit-on-blur input, read state or failure line** — use or add to `components/ui/*` (with an RTL test). A read's idle/loading/failed/empty is `ui/states::ReadState`; a failure's sentence is `ui/states::FailureLine`. <!-- probe: git grep -cE ".note-failure." -- webapp/components/*.tsx <= 1 --> <!-- probe: git grep -cE "role=.dialog." -- webapp/components/*.tsx <= 1 --> <!-- probe: git grep -cE "navigator\.clipboard" -- webapp/*.tsx <= 1 --> The two brand marks are `ui/VendorLogo` (who trained a model) and `account/providers.tsx::ProviderIcon` (who you signed in with).
- **Teaching prose goes through `ui/Term` or `ui/HoverCard`, never `title=`** (eslint `local/title-is-a-label`: a title is a label under 60 characters); operator vocabulary rides `lib/terms.ts::TERMS`.
- **No second table, measured-cell renderer or detail panel**: rows are `ui/DataTable`; <!-- probe: git grep -cE "<table" -- webapp/components/*.tsx == 0 --> measured cells are a PRESET of `measurements/MeasurementsPane` over `GET /datasets/{name}/cells`, opening in `measurements/CellPanel` inside `ui/SidePanel`. Grouping buckets served rows, never re-sorts them.
- **No second pipeline graph or lineage tree**: `dashboard/pipeline/PipelineFlow` and `candidates/Forest`; `candidates/DendrogramStrip` is the forest's paired layout under the bars, never a second tree. A channel's extent is its served `main_line` plus the seed runs that measured it (`extentKeys`); every drawn edge is the served descent (`descentOf`) — never chained from a round's winner, never a donor guessed.
- **What a panel copies is a derivation in `lib/derivations`** (`searchpointCopyChoices`); `CopyButton` hangs beside a label, never inside one.
- **An axis is one `ui/ValueList`** (start value = position 1, ticks = permitted set, lock DERIVED); `NodeConfigEditor` is the single editor, `ConfigMode` picks only the transport. **A row answers who may SEARCH it (`never_axis`/`movable_by`), whether this account may STEER it past `permitted` (`editable`), which widget EXPRESSES it (`kind`) and which call fact it is (`role`)** — every fence is server-side, never re-gated here, and no control keys on a param's name; the SCHEMA is outside the rows (`OutputContract`; `SchemaTreeEditor`).
- **A card header is ONE row** — `Toolbar` + `ToolbarSep` + `ToolbarSpacer`, rare controls in a `⋯` `Menu`; a control driving one region sits beside it.
- **"Where is this run" is `shell/masthead/RunMasthead`'s alone** (the run's bill is its SPEND figure, `SpendBuckets` its one breakdown). One header for every subject: `workspace.tsx::useViewedListing` names its title row, `shell/FigureRow` draws a run's served `figures`, each a `FAMILIES[f].glance` names being that view's door, any other open view a bare door; a column's close is its own head's.
- **A run bound is a CAP on every label** (the account's is the ALLOWANCE); one parse, `lib/run-limits.ts::parseCap`.
- **Text and numeric controls commit on Enter or blur** — `ui/CommitInput`. **A lit chip wears the ink of what it drew**, lit from the served value.
- **A painted surface is a control** — SVG/tree nodes get keyboard operability and a `role`, a `<canvas>` an `aria-label`. **A canvas paints no detail over its own marks** — a tap selects and the reading opens in the DOM below; Chart.js `Tooltip` is never registered (`lib/chart.ts`). <!-- probe: git grep -cE "Tooltip" -- webapp/lib/chart.ts == 0 -->

- **Render-cost guards**: a chart consuming `dash` is `React.memo`-wrapped, its `useMemo`s keyed on the narrowest derivation (`dash?.rounds`); geometry memoizes on structure, live overlays (`valueByKey` / `thetaByKey`) stay outside it; anything in a chart's `options` memo is a stable identity.
