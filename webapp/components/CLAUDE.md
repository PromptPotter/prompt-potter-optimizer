# webapp/components — CLAUDE.md

- **Three tiers, decided top-down:** a **primitive** (`ui/`), **chrome** (`shell/`: what only `AppShell` mounts), or **one surface** (a folder each, its folders domain regions, never widget kinds). A widget several surfaces host is a surface of its own, never chrome. A host hands a reading **IDENTITY props, never SOURCE props** ([`../lib/CLAUDE.md`](../lib/CLAUDE.md) § Display-data sources).
- **No second modal, popover, dropdown, toggle-chip, segmented control, toolbar, clipboard copy, commit-on-blur input, read state or failure line**: use or add to `components/ui/*` (with an RTL test). <!-- probe: git grep -cE ".note-failure." -- webapp/components/*.tsx <= 1 --> <!-- probe: git grep -cE "role=.dialog." -- webapp/components/*.tsx <= 1 --> <!-- probe: git grep -cE "navigator\.clipboard" -- webapp/*.tsx <= 1 --> Teaching prose goes through `ui/Term` or `ui/HoverCard`, never `title=` (eslint `local/title-is-a-label`).
- **No second table, measured-cell renderer or detail panel**: rows are `ui/DataTable` <!-- probe: git grep -cE "<table" -- webapp/components/*.tsx == 0 -->; measured cells are a PRESET of `measurements/MeasurementsPane`. Grouping buckets served rows, never re-sorts them.
- **No second pipeline graph or lineage tree** (`pipeline/PipelineFlow`; the lineage tree is one derivation, `candidates/lineage-tree.ts::layout`, laid PAIRED under the bars as `DendrogramStrip` or FREED as `Forest`, one `TreePairing` button between them); every drawn edge is the served descent, never chained from a round's winner. **`NodeConfigEditor` is the single config editor**; every fence on a row is server-side, never re-gated here, and no control keys on a param's name.
- **"Where is this run" is `shell/masthead/RunMasthead`'s alone**; one header for every subject. A lit chip wears the ink of what it drew, lit from the served value. **A card header is ONE row** (`Toolbar` + `ToolbarSep` + `ToolbarSpacer`, rare controls in a `⋯` `Menu`). **A run bound is a CAP on every label** (the account's is the ALLOWANCE); one parse, `lib/run-limits.ts::parseCap`.
- **A control never stops a press; a frame takes only its own** (`ui/press.ts::ownPress`): a press on a control inside it, or in a portal it opened (a menu, reached through the React tree), is that control's. <!-- probe: git grep -cE "stopPropagation\(" -- webapp/components/*.tsx == 0 -->
- **A painted surface is a control** (keyboard operability and a `role`; a `<canvas>` an `aria-label`). **A canvas paints no detail over its own marks**: a tap opens the reading in the DOM below. <!-- probe: git grep -cE "Tooltip" -- webapp/lib/chart.ts == 0 -->
- **A chart consuming `dash` is `React.memo`-wrapped**, its memos keyed on the narrowest derivation; anything in a chart's `options` memo is a stable identity.
